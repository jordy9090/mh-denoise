# Repository agent instructions

## Working principles

- Inspect before editing. Verify assumptions from available files.
- Define measurable completion criteria.
- Keep changes minimal and task-scoped.
- Run focused checks and reuse valid prior results.
- Report actual changes, verification results, and blockers.
- Ask only consequential questions that available evidence cannot resolve.

## Research integrity

- Preserve frozen data, splits, labels, checkpoints, and evaluation contracts.
- Never substitute missing inputs or mix legacy, pilot, and final data.
- Start new expensive jobs only with explicit scoped authorization.
- Match paper claims and figures to verified implementation and results.
